v0.2.2 · 贴纸系统 + 定时消息调度器

2026年6月14日

贴纸系统

  • 内置 2 套贴纸包、14 款手绘 SVG 贴纸（表情心情 x12 + 可爱动物 x8，跨包复用）
  • 贴纸选择面板：4 列网格 + 包切换标签（表情心情 / 可爱动物）+ hover 高亮 + 点击即发
  • 贴纸消息渲染：200px 大尺寸、无气泡背景浮动显示（Telegram 风格）、带头像 + 时间戳 + 表情反应
  • InputBar 贴纸按钮（Sticker 图标），紧邻 Emoji 按钮
  • 完整发送管线：dataURI → Blob → uploadFile → sendMessage

定时消息调度器

  • 主进程 MessageScheduler 单例：每 15 秒轮询数据库，到期消息自动清除 scheduled_at 并发布
  • 定时消息管理面板：查看待发送列表、格式化倒计时（天/小时/分钟/秒）、单条取消、自动刷新
  • 集成到 ChatView 更多菜单（Clock 图标入口）+ IPC 事件监听自动刷新消息列表
  • 渲染端 setTimeout 精确定时 + 主进程持久化调度器互补，重启/崩溃不丢失
  • 应用退出自动停止调度器，启动后自动开始轮询

文档

  • PRD 全面扩展：从 1714 行 → 1680 行（15 个一级章节），整合架构/权限/E2EE 加密/远程 WSS/TTS 评估/有声书方案/视频嗅探/CI/CD/许可证合规全部内容
  • 未完成工作清单更新：Pre-Phase-2 全部清零（MatrixProvider / 贴纸 / 定时消息 / 全文搜索 / 大 EPUB 误判 全部完成）

v0.2.0 · TTS 语音合成 + EPUB 有声书 + 音频导出

2026年6月7日

TTS 语音合成系统

  • 13 引擎集成：4 个本地离线（Sherpa-ONNX+Kokoro 中英主力、Supertonic 极速英文、PaddleSpeech 开源中文、Piper CLI 40+ 语言兜底）+ 9 个远程云端（阿里云 Qwen3-TTS / 火山引擎 / 腾讯云 / 百度 / OpenAI / Google / Azure / Amazon Polly / ElevenLabs）
  • 消息右键朗读 + AI 自动语音回复 + ChatView 快捷朗读 + 消息气泡内联 TTS 播放器
  • 多引擎切换：TTS 设置页查看引擎状态，展开选择语音、一键试听
  • 语速 0.25x-4.0x + 音调 0.5x-2.0x 滑块调节，100ms 防抖自动保存到 SQLite
  • API Key AES-256-GCM 本地加密存储（PBKDF2 + 0o600 权限）+ 隐私声明确认
  • 引擎降级链：本地优先 → 远程按需 → 超时 5s 自动回退本地
  • 合成缓存（TTSCache）：key = engineId + voiceId + speed + SHA256(text)，重复请求直接复用
  • 语音模型静默下载：首次启动 30s 后后台下载 Kokoro（~160MB），HTTP 断点续传 + 进度推送
  • 流式合成：长文本分段逐句合成 + AbortController 取消

EPUB 有声书

  • 核心流水线：文本分句 → TTS 逐句合成 → 播放 → 当前句高亮 → 自动翻页
  • 中英文混合分句 + 非正文过滤（页码/脚注/引用标记自动跳过）
  • 断点续听：重新打开提示从上次位置继续，恢复 speed/pitch/playbackRate
  • 底部抽屉播放器（35vh）：字幕横滚、独立 playbackRate 0.5x-3.0x、可拖拽进度条
  • 浮动耳机按钮：右下角 48px 圆形，20s 无操作自动折叠半圆贴边
  • 定时关闭：15/30/60/90 分钟 / 当前章节结束
  • 书签管理：命名/增删/跳转/恢复语音配置
  • 导出音频：整章批量合成 → FFmpeg concat 拼接 → 系统保存对话框导出 WAV/MP3
  • 播放历史：audiobook_history 表，按书/全局查询统计

消息状态系统（Telegram 风格五态）

2026年6月5日

新增功能

  • Telegram 风格五态消息指示器：🕐 发送中 → ✓ 已发送 → ✓✓ 已送达 → ✓✓ 已读 → ❌ 发送失败
  • 频道消息仅显示 👁 眼睛图标 + 已查看人数，不显示勾选标记（频道无双勾）
  • 消息详情弹窗（右键菜单 → 查看详情）：显示创建/发送/送达/已读时间线 + 状态徽章
  • 消息乐观发送：文字消息立即显示在 UI，无需等待服务端确认
  • 发送失败自动重试：指数退避 1s / 2s / 4s，最多 3 次，失败后显示红色 ❌
  • 文件上传中显示占位界面（类型图标 + 文件名 + 进度条 + 百分比），不再显示"无法找到"错误

改进

  • 上传完成后不再出现重复消息气泡
  • WSS 服务端新增 message_delivered / message_read 实时事件推送
  • readCount 阅读计数全房间实时广播
  • Matrix m.receipt 已读回执事件自动映射为 status: 'read'
  • 所有 Provider 统一适配 MessageStatus 五态字段

v0.1.0

2026年5月7日

首个正式版本发布

unobox 由作者一人使用多个 AI Agent（Claude、Antigravity、Claude Code、Gemini 等）复合自动开发完成，从构思到首个版本发布耗时近 20 天。

核心功能

  • 搭建 unobox 桌面端基础框架（Electron + React + TypeScript + Vite）
  • 实现 Telegram 风格的三栏式聊天布局 + 自定义无边框标题栏
  • IServerProvider 统一接口 + ProviderManager 多服务器热插拔管理
  • LocalProvider：基于 better-sqlite3 纯本地存储，完全离线可用
  • WebSocketProvider：自建 WS 服务端连接器，支持多房间、实时消息广播、文件传输
  • MatrixProvider：Matrix/Synapse 协议适配，支持联邦网络通信
  • 完整消息功能：文本/图片/视频/语音/文件/GIF/Emoji，引用/转发/编辑/删除/固定/反应/已读
  • 群组管理：创建/邀请/踢出/角色管理/管理员 6 项权限配置/群公告
  • Channel 频道：服务器同步 / 本地存储双模式、定时发布、阅读量、评论区、订阅者管理
  • Bot 框架：注册/命令处理/自动回复/内联键盘/Webhook 回调
  • AI 智能聊天（计划外）：8 种接口、流式输出、思考过程可视化、会话持久化
  • CI/CD：GitHub Actions 自动构建三平台 + Release 发布 + 静态官网部署
  • 自动更新：electron-updater 集成 + UpdateModal 更新提示弹窗
