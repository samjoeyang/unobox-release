版本更新日志

unobox 所有版本的发布说明均在此归档，每一次迭代都为你带来更安全、更优异的体验。

v0.1.2

2026年5月22日

新增功能

  • 重构 CI/CD 自动化构建流水线，支持 Windows (.exe) 和 macOS (.dmg, .zip) 跨平台打包与统一发布

v0.1.1

2026年5月22日

缺陷修复

  • 修复各 packages 缺少单元测试文件导致 CI 运行失败的问题
  • 优化桌面端 CI 编译验证任务，避免在非发布流程下执行耗时的二进制封包提升稳定性

v0.1.0

2026年5月21日

新增功能

  • 搭建 unobox 桌面端基础框架（Electron + React + Vite）
  • 实现 Telegram 风格的三栏式聊天布局
  • 引入 better-sqlite3 本地轻量级数据库存储，支持离线消息缓存
  • 搭载 WssServerManager，内置局域网 WebSocket 调试服务端
  • 注册设备指纹接口，获取硬件唯一特征 ID
  • 实现自定义精美无边框标题栏

优化与改进

  • 优化了断网重连时的增量消息及会话状态同步策略
  • 提升了暗黑主题自适应流畅度

缺陷修复

  • 修复了主进程数据库执行大批量语句时的卡顿问题
