快速开始与使用指南

只需三步，在任何场景下搭建属于自己的安全私密通讯。

1

下载并安装 unobox 桌面客户端

从 官网首页 根据你的操作系统下载对应版本：

  • 🪟 Windows：下载 .exe 安装包，双击运行，按向导一键完成安装。
  • 🍎 macOS：下载 .dmg 磁盘镜像，打开后将 unobox 拖入 Applications 文件夹。
💡 首次启动 macOS 版本时，系统可能提示"无法验证开发者"。请前往 系统设置 → 隐私与安全性，点击"仍要打开"即可。
2

首次启动：选择通信模式

首次打开 unobox 时，会显示欢迎引导界面。点击 "开始配置"，然后从三种通信模式中选择一种：

🔌 WebSocket 局域网 🌐 Matrix 联邦网络 💾 本地存储
🔌 模式一：WebSocket 局域网（推荐）

适合局域网（家庭/公司/内网）中多台设备互联通信。分为两个角色：

  • 服务端模式（主机）：选择"服务端模式（本地承载）"，填写端口（默认 8080）、访问密码（系统会自动随机生成）和本机用户名，点击"保存并连接"启动内置 WebSocket 服务器。
  • 客户端模式（其他设备）：选择"客户端模式（连接远端）"，填入主机的局域网 IP + 端口（如 ws://192.168.1.100:8080）和对应的访问密码，点击"保存并连接"即可加入。
服务端信息（其他人连接时需要提供）： 地址：ws://[主机局域网IP]:8080 密码：（服务端页面中显示的随机 Token）
📢 主机的局域网 IP 可以在"服务端模式"配置面板的 "局域网接入信息" 提示框中直接复制，无需自行查找。
🌐 模式二：Matrix 联邦网络

适合连接全球公开的 Matrix/Synapse 服务器或自建 Synapse 私有节点，打破地理隔阂实现跨网络私密通信。

  • 在 Homeserver URL 中填入 Matrix 服务器地址（如 https://matrix.org 或你的私有节点）。
  • 填写用户名（如 samjoeyang，系统会自动组成 @samjoeyang:matrix.org 格式）。
  • 使用账号密码或 Access Token（syt_...）登录，点击"保存并连接"。
🌍 Matrix 模式支持与全球任何 Matrix 服务器的用户聊天，实现真正的去中心化私有通信。你可以在 matrix.org 注册免费账号进行体验。
💾 模式三：本地存储

无需网络、无需服务器，所有消息保存在本机 SQLite 数据库中。适合单机记录、离线备忘或测试使用。

  • 选择"本地存储"后，直接点击"保存并连接"即可，无需填写任何地址或密码。
3

创建会话并开始聊天

连接成功后，即可看到 Telegram 风格的三栏主界面。从这里开始你的私密通讯：

  • 📢 创建频道（Channel）：点击聊天列表左上角的"+"图标，选择"创建频道"，输入名称后即可完成，适合广播消息或公告。
  • 👥 创建群组（Group）：同样通过"+"图标选择"创建群组"，邀请其他已连接的成员加入，进行多人对话。
  • 💬 发送消息：进入任意频道或群组后，在底部输入框中输入消息并按 Enter 键发送。支持换行（Shift+Enter）。
  • 🔔 在线提示：局域网模式下，当其他设备连入服务器时，系统会自动弹出桌面通知提醒。
⚙️ 更换主题 / 调整字体大小：点击左上角的"设置"图标（⚙️）进入设置页，在 外观 选项中可切换日间/深色主题，以及拖动滑块调整消息字体大小（12–24px）。
💡

管理服务器与切换连接

unobox 支持同时管理多个服务器配置，方便在不同网络环境中快速切换：

  • 进入 设置 → 服务器管理，可以新增、编辑或删除已配置的服务器。
  • 点击左侧功能导航栏中的服务器头像图标，可快速在多个服务器之间切换。
  • 应用启动时会自动尝试重新连接上次活跃的服务器，断线后也会自动增量同步离线期间的消息。
🔄 自动更新：客户端内置静默更新检测，启动 5 秒后自动检查是否有新版本。也可在 设置 → 外观 → 关于与自动更新 中手动点击"检查新版本"。
